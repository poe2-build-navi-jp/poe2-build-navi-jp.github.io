PoE2 パスファインダー（Pathfinder）｜特徴・主なノード・おすすめビルド（0.5.5）

ページ更新：2026-11-26編集：オカピ研究所 · 情報源・確認方法

パスファインダーはレンジャーのアセンダンシー（上位職）です。毒、フラスコ、混合物（コンコクション）スキルと、他職業の開始地点へ伸ばすノードが中心です。

どんなアセンダンシーか

毒、フラスコ、混合物（コンコクション）スキルと、他職業の開始地点へ伸ばすノードが中心です。[1]

レンジャーにはほかにデッドアイがあります。同じ職業でも、選ぶアセンダンシーで得意な戦い方が変わります。

Tier評価（0.5.5）

評価元評価対象
Maxroll[2]A0.5.5のリーグスタート
PathofExile.gg[4]B0.5時点のクラス・アセンダンシー評価

評価は各サイトの意見で、公式の強さ順ではありません。2つのサイトで評価が分かれています。評価時期と前提（リーグスタートか、装備がそろった後か）が違うためです。全アセンダンシーの比較は最強ビルドTier表で確認できます。

主なノード

PoE2DB日本語版にあるノードのうち、特徴が分かりやすいものを6つ挙げます。効果は要約です。正確な数値はゲーム内の表示で確認してください。[1]

おすすめビルド

このサイトには、パスファインダーの育成ガイドはまだありません。

MaxrollのビルドTier表にあるビルド

  • C Cold Spark（日本語名未確認）・パスファインダー
  • C ポイズンバーストアロー・パスファインダー
  • C スパイラルボレー（毒）・パスファインダー

Maxrollのリーグスタート向けビルドTier表（0.5.5）から、パスファインダーを使うビルドを抜き出しました。[3]

取得方法と注意

  • アセンダンシーは、試練（セケマの試練・混沌の試練）をクリアして得るポイントで振ります。手順は転職・試練攻略で解説しています。
  • ノードの効果と評価は0.5.5時点のものです。1.0で変更される可能性があります。1.0のバランス変更も確認してください。
  • ノードの名前は日本語版の翻訳に合わせています。英語名で探すときは、各ノードの下の英語表記を使ってください。
