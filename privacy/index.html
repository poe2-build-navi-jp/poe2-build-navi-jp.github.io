端末内への保存

現在レベルや選択したビルドなど一部の設定を、ログインなしで利用できるようブラウザーのlocalStorageへ保存します。通常の端末内保存は端末内で行います。任意の端末間同期を有効にした場合の取り扱いは次のとおりです。

任意のビルド公開・通報

「みんなのビルド」で公開内容を確認し、一般公開のチェックを入れて投稿した場合だけ、ビルド名・投稿者名・説明・予算・用途と、反映済みの装備・ジェム・パッシブ・レベル・敵・計算条件をAppDeployへ保存し、誰でも閲覧できる状態にします。個人メモ、編集中の装備入力、同期用の接続コードは公開用データに含めません。説明や装備の名前に個人情報を入力しないでください。

投稿の管理コードは端末のlocalStorageに保存し、投稿・自分の投稿確認・取り下げ時にサービスへ送信します。サーバーにはコードのハッシュを保存します。別のコードに切り替えると、以前のコードも端末内で切替用に保持します。コードを知る人は投稿を取り下げられます。共有URLにコードは含めません。紛失したコードを運営から復旧することはできません。

取り下げ時は稼働中の公開構成と一覧を削除します。再送による復活を防ぐため、投稿ID・管理用ハッシュ・処理履歴は保持します。第三者がすでにコピーした内容までは取り消せません。通報は理由・補足・対象投稿ID・重複防止用識別子を運営確認用として非公開で保存します。ホスティング事業者は通信元IP等のアクセス情報を処理する場合があります。暗号化した端末間同期の保管庫とは別のサービスです。

Publishing is optional and requires a preview and explicit consent. Public snapshots include the displayed title, author, description, budget and applied build inputs. Private notes, equipment-editor drafts and sync codes are excluded. Keep your management code private; it allows withdrawal. Withdrawal removes the live public snapshot, while a hashed processing receipt prevents replay. Reports are stored privately for review.

任意のビルド同期

シミュレーターで「新しく同期を始める」または接続コードによる接続を選んだ場合だけ、名前付きの構成と比較記録を端末間で同期します。構成名・メモ・装備・ジェム・パッシブ・比較条件を端末で暗号化し、AppDeployの保管庫へ暗号文として保存します。一時編集中の自動保存、記事の閲覧履歴、他の端末内設定は同期対象に含めません。

サーバーには保管庫の識別子、認証用トークンのハッシュ、更新番号、暗号文を保存します。復旧用の接続コードと復号鍵はサーバーへ送りません。接続コードはこの端末のlocalStorageに保存し、保管庫を読むために利用します。同期リクエストにコードや構成本文を解析イベントとして添付しません。ホスティング事業者は通信元IPなどのアクセス情報を処理する場合があります。

接続コードを知る人は保存内容を復号できます。コードを紛失すると運営からの復旧はできません。「この端末の接続を解除」で端末の接続情報を消せます。「保管庫を無効化」で稼働中の保管庫の暗号文を削除し、同じコードでの読み書きを停止します。各端末に残る構成は、構成の削除機能で個別に管理できます。

Cross-device sync is optional. Named builds and comparison records are encrypted on your device before storage with AppDeploy. The recovery code and decryption key are not sent to the server. Keep the code private: it grants access to the vault. Disconnecting removes this device’s connection; revoking the vault removes its live encrypted snapshot and disables the code. Local saves remain on each device.

Google Analytics

本サイトは利用状況を把握し改善するため、Google Analyticsを使用します。Google AnalyticsはCookie等を利用し、閲覧ページや利用環境などの情報を収集する場合があります。収集情報の取り扱いは、Googleのサービス利用サイトから収集した情報の使用についてをご確認ください。

育成ガイドの利用結果

個別ビルドの任意フォームでは、共有ボタンを押したときにビルド識別子・Lv帯・掲載パッチ・選択した困りごと・結果をGoogle Analyticsのイベントとして送信します。名前、メールアドレス、自由記述、端末内のチェック履歴は、このフォームから送信しません。回答は記事改善の参考に使い、返信や性能・成功率の証明には使用しません。

広告配信

本サイトは第三者配信の広告サービス「Google AdSense」を利用しています。

  • Googleなどの第三者配信事業者は、Cookieを使用して、ユーザーが本サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信します。
  • Googleが広告Cookieを使用することにより、Googleとそのパートナーは、本サイトや他のサイトへのアクセス情報に基づいて、適切な広告をユーザーに表示できます。
  • ユーザーは、Googleの広告設定で、パーソナライズ広告を無効にできます。また、www.aboutads.infoにアクセスすれば、パーソナライズ広告に使われる第三者配信事業者のCookieを無効にできます。

Googleによる広告でのCookieの使い方は、Googleの広告に関するポリシーをご確認ください。
