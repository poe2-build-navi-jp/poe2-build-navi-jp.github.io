DICTIONARY

スキルジェム

一言でいうと

スキルパネルにはめて、攻撃や魔法などのスキルを使えるようにするジェム。

初心者向け説明

スキルジェムは、スキルパネルにはめて攻撃や魔法などのスキルを使えるようにするジェムです。はめたスキルはキーに割り当てて使います。常駐するバフや永続ミニオンを使うSpiritジェムもスキルジェムの一種です。

基本のしくみ

  • 同時にセットできるスキルジェムは通常9個まで。Unset Ring（指輪のベースタイプ）などでスキル枠を増やせる。
  • 使うには、ジェムのレベル条件と能力値（筋力・器用さ・知性）の条件を満たす必要がある。ジェムのレベルが上がるほど条件も上がる。
  • スキルジェムはUncut Skill Gemから作る。作ったジェムのレベルは、使ったUncut Skill Gemのレベルになる。
  • 作ったジェムは、Uncut Skill Gemを使ってレベル20まで上げられる。品質はGemcutter's Prismで5%ずつ、20%まで上げられる。
  • Spiritジェムは、Uncut Spirit Gemからしか作れない。

主力が使えるまでの時間

強力なスキルほど、使えるようになるまでのレベルが高いことがあります。ビルドによっては、主力を使える条件がそろうまで別のスキルで進めます。

なぜ重要？

スキルジェムのレベル条件を知らないと、「主力スキルがまだ使えない」理由が分からずに迷います。ジェムのレベルは火力に直結するため、Uncut Skill Gemを主力に優先して使うことも大切です。

このサイトのビルドでの例

  • シールドウォール・スミス：シールドウォールはTier 7のジェムで、使えるのはLv22から。
  • アイスショット・デッドアイ：アイスショットは、レベル9のジェムの必要キャラクターレベルであるLv31から。
  • ワーリングアサルト・マーシャルアーティスト：ワーリングアサルトはTier 11のジェムで、使えるのはLv41から。
  • 相棒スピリットウォーカー：テイムビーストはTier 7のジェムで、序盤は使えない。

次にすること

自分のビルドの主力スキルを何Lvから使えるかをビルドページで確認し、それまでに使うスキルとUncut Skill Gemの使い道を決めます。
