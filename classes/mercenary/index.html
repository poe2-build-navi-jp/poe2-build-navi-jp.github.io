PoE2 マーセナリーおすすめビルド・育成｜0.5.5

クロスボウや武器切替を使う遠距離タイプ。このページでは、掲載中のおすすめビルドとLv1〜30の育て方を確認できます。

遠距離武器切替
対応環境 0.5.5・最新確認 0.5.5d・最終確認 2026-10-04

マーセナリーはどんな職業？

クロスボウを扱い、状況に応じた攻撃や武器セットの切替を使う職業です。掲載中のビルドでは、ツイスターを中心に育成します。

この職業はこんな人向け

  • 遠距離から戦いたい
  • 武器を切り替えて対応したい
  • 段階的な育成手順が欲しい

マーセナリーは初心者向け？

掲載ビルドは現在Lv別の育成手順を確認できます。武器セットや必要能力の確認項目が、単一武器の構成より多くなります。

マーセナリーはどのビルドを選ぶ？

  • ツイスター・ジェムリング序盤からツイスターを使い、武器セットを切り替えて進めたい人
  • グレネード・ジェムリング遠距離からグレネードを使い、同じ攻撃軸でLv1から進めたい初心者

マーセナリーの序盤Lv1〜30の育て方

掲載ビルドの確認済み手順を、Lv1〜10 → Lv11〜20 → Lv21〜30の順に進めてください。

ツイスター・ジェムリング

Lv1〜10：ワーリングスラッシュ×3 → ツイスター

Lv11〜20：ワーリングスラッシュ → ツイスター。単体にはパリィ → Fangs of Frostも使用。

Lv21〜30：ワーリングスラッシュ×3 → ツイスターを継続。

序盤の育成手順を見る

グレネード・ジェムリング

Lv1〜10：Explosive Grenade。補助にFrost BombとFlash Grenade

Lv11〜20：Explosive Grenade + Flash Grenade。入手後Gas Grenade

Lv21〜30：Explosive Grenade + Flash/Gas Grenade

序盤の育成手順を見る
