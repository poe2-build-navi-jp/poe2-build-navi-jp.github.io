モンク / マーシャルアーティスト

ワーリングアサルト・マーシャルアーティスト

近接で移動しながら戦い、Lv1からEndgameまで同じページで進めたい人

  • 主力：ワーリングアサルト（Whirling Assault）
  • 操作：中（Lv41で構成切替）
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

先に知る弱点：ワーリングアサルトはLv41まで使えないため、キャンペーン途中でスキルを切り替える必要がある。

マーセナリー / ジェムリング・リージョネア

ツイスター・ジェムリング

序盤からツイスターを使い、武器セットを切り替えて進めたい人

  • 主力：ツイスター（Twister）
  • 操作：複数スキルの順番管理
  • SSF適性は確認中
  • 価格：固定相場を断定しません

序盤の使いやすさ：Lv1〜10はワーリングスラッシュ×3 → ツイスターで進めます。

先に知る弱点：ワーリングスラッシュはマナ消費を抑えるためLv1維持が推奨され、誤って上げない注意が必要。

  • 主力：シールドウォール（Shield Wall）
  • 操作：Lv22で主力を切替
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

序盤の使いやすさ：Lv1〜10はローリングスラム + ボーンシャッターで進めます。

先に知る弱点：主力のシールドウォールはLv22まで使えない。

  • 主力：ケラリの幻惑 / ルザンの罠
  • 操作：最初のアセンダンシーで構成切替
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

ハントレス / スピリットウォーカー

相棒スピリットウォーカー

相棒を主力にし、育成途中の大きな構成変更も楽しめる人

  • 主力：テイムビースト（Tame Beast）
  • 操作：Act 3で大きく構成切替
  • SSF適性は確認中
  • 価格：固定相場を断定しません

先に知る弱点：テイムビーストはTier 7ジェムまで使えず、相棒型への切替はAct 3・2回目の試練後が推奨されている。

レンジャー / デッドアイ

アイスショット・デッドアイ

弓で遠距離から戦い、周回と単体攻撃を使い分けたい初心者

  • 主力：アイスショット（Ice Shot）
  • 操作：Lv31で主力を切替
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

序盤の使いやすさ：Lv1〜10はライトニングアロー + ライトニングロッドで進めます。

先に知る弱点：アイスショットはLv31まで解禁されないため、序盤はライトニングアローとライトニングロッドを使う。

ウィッチ / インファーナリスト

スナイパーミニオン・インファーナリスト

召喚した仲間に攻撃を任せ、敵の動きと回避へ集中したい初心者

  • 主力：スケルタルスナイパー / スペクター
  • 操作：Act 3とLv67前後で召喚対象を切替
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

序盤の使いやすさ：Lv1〜10はスケルタルスナイパー + Flame Wall。Contagion + Unearthを周回補助に使用で進めます。

先に知る弱点：移動速度は高速周回型より遅く、狭い場所ではミニオンAIが詰まる場合がある。

Lv1〜10の育成を見る

ドルイド / オラクル

植物オラクル

  • 主力：Entangle / Thrashing Vines
  • 操作：主力はLv1から継続、後半に自動発動を追加
  • SSF適性は確認中

先に知る弱点：防御は装備依存で、後半はESと混沌耐性を整える必要がある。

Lv1〜10の育成を見る
