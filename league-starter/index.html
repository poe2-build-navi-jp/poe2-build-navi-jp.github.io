LEAGUE STARTER

PoE2 リーグスターターおすすめビルド

最初のキャラクターで育成を始められる、0.5.5対応の候補を比較します。固定価格や未確認の強さは断定しません。

対応：0.5.5最終確認：2026-09-13

選定条件

掲載資料でリーグ開始から育成できることを確認できる候補です。高額ユニークへの依存やSSF適性が確認できない場合は、そのまま明記しています。

モンク / マーシャルアーティスト

ワーリングアサルト・マーシャルアーティスト

近接で移動しながら戦い、Lv1からEndgameまで同じページで進めたい人

  • 主力：ワーリングアサルト（Whirling Assault）
  • 操作：中（Lv41で構成切替）
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

先に知る弱点：ワーリングアサルトはLv41まで使えないため、キャンペーン途中でスキルを切り替える必要がある。

  • 主力：ツイスター（Twister）
  • 操作：複数スキルの順番管理
  • SSF適性は確認中
  • 価格：固定相場を断定しません

先に知る弱点：ワーリングスラッシュはマナ消費を抑えるためLv1維持が推奨され、誤って上げない注意が必要。

  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

  • 主力：ケラリの幻惑 / ルザンの罠
  • 操作：最初のアセンダンシーで構成切替
  • SSF対応の根拠を確認済み
  • 価格：固定相場を断定しません

  • 主力：テイムビースト（Tame Beast）

  • SSF適性は確認中
  • 価格：固定相場を断定しません

先に知る弱点：テイムビーストはTier 7ジェムまで使えず、相棒型への切替はAct 3・2回目の試練後が推奨されている。

  • 主力：スケルタルスナイパー / スペクター
  • 操作：Act 3とLv67前後で召喚対象を切替
