# アプリの土台・公開への引き継ぎ

現在はiPhone/iPad・Androidのソースとビルドの土台を準備する段階。App Store / Google Playへの提出や一般配布は行わない。

本体は `https://poe2-build-navi-jp.github.io/` を読み込む。計算画面・ゲームデータ・ジェム・記事の修正はWeb側へ公開すれば反映できる。アプリへの同梱コピーの更新は不要。起動時はHTMLを再検証し、起動中は最長15秒間隔と画面復帰・オンライン復帰時に新版を確認する。「更新あり」から保存内容を残したまま読み直せる。

入力途中に強制再読み込みはしない。端末内保存・バックアップ・復元、装備写真の選択と撮影、OS共有、信頼済みオリジンだけのネイティブ連携を残す。変更するのはWeb更新の取得と起動の安定性に関係する範囲。

## 公開する時の作業

1. GitHub Actionsの **Build POE2 native apps** が成功した版を使う。ビルド番号はiOS/Androidとも3。
2. iPhone/iPad・Android実機で起動、再起動後の保存、撮影、ファイル保存、Web更新通知と反映を確認する。
3. Apple Developer Team / Android署名、Bundle ID、ストアの説明・画像・プライバシー申告を確定する。
4. 署名してTestFlight等で配布確認し、公開すると決めた時にストアへ提出する。

CIのiOSアーカイブとAndroid AABは署名前の準備用。ネイティブ画面、権限、SDK、課金などを変えた時は、Web更新と別にストア版を更新する。手順の詳細は [README.md](README.md)。
