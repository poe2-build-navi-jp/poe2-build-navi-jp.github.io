TIER LIST / PATCH 0.5.5

PoE2 最新ビルドTierリスト

初心者が最初の1体を選ぶための暫定Tierです。強さだけの順位ではなく、Lv1から迷わず進められるかを重視します。

対応：0.5.5最終確認：2026-09-10

このTierの見方

強さの断定順位ではありません。現在掲載している0.5.5のビルドを、初心者がLv1から育成を始めやすいか、操作や途中切替が分かりやすいか、確認資料が揃っているかで暫定分類しています。火力・周回・ボス・防御の数値比較は、同条件の検証がないため採点していません。

S Tier

S

レンジャー / デッドアイ

アイスショット・デッドアイ

初心者向け遠距離として目的が明確で、序盤用スキルからアイスショットへ移る時期も確認できます。

強み

Lv1〜30の育成構成と、Lv31以降のアイスショット構成が段階別に公開されている。

弱み

アイスショットはLv31まで解禁されないため、序盤はライトニングアローとライトニングロッドを使う。

  • 初心者適性：弓で遠距離から戦い、周回と単体攻撃を使い分けたい初心者
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：Lv31で主力を切替
現在Lvから進める
S

ウォリアー / スミス・オブ・キタヴァ

シールドウォール・スミス

耐久型のリーグスターターを探す人向けで、主力へ切り替えるLv22までの手順も確認できます。

強み

最初のアセンダンシー取得後はキャンペーンで耐久を得やすい。

弱み

主力のシールドウォールはLv22まで使えない。

  • 初心者適性：装備を整えやすい耐久型のリーグスターターを探している人
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：Lv22で主力を切替
現在Lvから進める
S

ウィッチ / インファーナリスト

スナイパーミニオン・インファーナリスト

攻撃をミニオンへ任せやすく、初心者が回避と位置取りへ集中しやすい構成です。

強み

各Act、Interlude、Lv67〜90まで段階別資料が公開されている。

弱み

移動速度は高速周回型より遅く、狭い場所ではミニオンAIが詰まる場合がある。

  • 初心者適性：召喚した仲間に攻撃を任せ、敵の動きと回避へ集中したい初心者
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：Act 3とLv67前後で召喚対象を切替
現在Lvから進める

A Tier

A

ドルイド / オラクル

植物オラクル

Lv1から同じ主力を継続しやすい一方、後半の防御は装備確認が必要です。

強み

Lv1からEndgameまでEntangleを主力として継続できる。

弱み

防御は装備依存で、後半はESと混沌耐性を整える必要がある。

  • 初心者適性：Lv1から同じ主力を使い、少ない基本操作で植物ビルドを育てたい初心者
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：主力はLv1から継続、後半に自動発動を追加
現在Lvから進める
A

モンク / マーシャルアーティスト

ワーリングアサルト・マーシャルアーティスト

移動しながら戦えますが、Lv41で主力を切り替える準備が必要です。

強み

ワーリングアサルトで移動しながら攻撃でき、マップを進みやすい。

弱み

ワーリングアサルトはLv41まで使えないため、キャンペーン途中でスキルを切り替える必要がある。

  • 初心者適性：近接で移動しながら戦い、Lv1からEndgameまで同じページで進めたい人
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：中（Lv41で構成切替）
現在Lvから進める
A

ソーサレス / ディサイプル・オブ・ヴァラシュタ

砂と炎のヴァラシュタ

育成資料は揃っていますが、最初のアセンダンシー取得時に構成が変わります。

強み

Lv1からキャンペーン、Endgameまでの段階別ガイドが公開されている。

  • 初心者適性：召喚型でも、自分で指示スキルを使う術師風の操作を楽しみたい人
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：最初のアセンダンシーで構成切替

B Tier

B

マーセナリー / ジェムリング・リージョネア

ツイスター・ジェムリング

序盤から主力を使えますが、複数スキルと武器セットの管理が必要です。

強み

  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし

相棒スピリットウォーカー

相棒型の目的は明確ですが、Act 3で大きな構成変更があります。

強み

弱み

  • 初心者適性：相棒を主力にし、育成途中の大きな構成変更も楽しめる人
  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：Act 3で大きく構成切替
現在Lvから進める

ウィッチ / リッチ

ED・コンテージョン リッチ

Lv1から育成できますが、複数スキルとマナ管理が必要で、現在の確認資料は1件です。

  • 周回・ボス・防御：同条件の数値比較は未採点
  • 予算：固定価格なし
  • 操作：低〜中（マナ管理あり）
