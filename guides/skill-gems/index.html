BEGINNER GUIDE

スキルジェムの使い方

Uncut Skill Gemを手に入れたら、主力に使うか・今のLvで使えるかを確かめてから作ります。

今日確認すること

  1. 最優先ビルドページで主力スキルが使えるLvを確認する
  2. 次Uncut Skill Gemは主力と今使うスキルに優先して使う
  3. その次Lvが上がったらスキルジェムのレベルも上げる

初心者向け説明

PoE2のスキルジェムは、敵を倒して手に入るUncut Skill Gem（未加工のスキルジェム）から、自分で好きなスキルを選んで作ります。作ったジェムはスキルパネルにはめると使えるようになり、キーに割り当てて使います。

迷いやすいのは「どのスキルを作るか」と「手に入ったUncut Skill Gemをどこに使うか」です。このページでは、作る前の確認と使い道の順番をまとめます。用語の意味だけを知りたい場合は、用語辞典の「スキルジェム」を見てください。

Uncut Skill Gemを手に入れたら

  • 使うと、スキルを選ぶ画面（Gemcutting）が開く。一覧は自分の職業に合うカテゴリから順に並ぶ。
  • 作ったジェムのレベルは、使ったUncut Skill Gemのレベルになる。
  • 作ったジェムは、別のUncut Skill Gemを使ってレベル20まで上げられる。装備中のジェムは「Equipped Gems」の欄から選べる。
  • 同じスキルジェムを2つ同時にはめることはできない（0.3.0で変更）。

ジェムのレベルと必要なキャラクターLv

Gemcuttingの一覧では、スキルがジェムのレベル（ローマ数字）ごとに分かれています。Path of Exile 2 Wikiの一覧に載っている、それぞれの必要キャラクターLvは次のとおりです。

  • レベルI：Lv1
  • レベルIII：Lv6
  • レベルV：Lv14
  • レベルVII：Lv22
  • レベルIX：Lv31
  • レベルXI：Lv41
  • レベルXIII：Lv52

主力が使えるまでの進め方

主力スキルのジェムのレベルが高いと、そのLvになるまで別のスキルで進みます。途中で使うスキルは、ビルドページの育成ロードマップに書かれたものを使い、自己判断で増やしすぎないのが安全です。

スキルジェムを使うには、レベル条件に加えて能力値（筋力・器用さ・知性）の条件も満たす必要があります。ジェムのレベルを上げると条件も上がるため、上げた直後に使えなくなっていないかを確認します。

よくある失敗

  • 使わないスキルを作ってUncut Skill Gemを使い切り、主力のレベルが上がらない。
  • ジェムのレベルだけ上げて、能力値の条件が足りずに使えなくなる。
  • 主力が使えるLvを確認せず、早い段階で作ろうとして一覧に出てこない。

このサイトのビルドでの例

  • シールドウォール・スミス：シールドウォールはレベルVIIのジェムのため、Lv22までは別のスキルで進む。
  • アイスショット・デッドアイ：アイスショットはレベルIXのジェムのため、使えるのはLv31から。
  • ワーリングアサルト・マーシャルアーティスト：ワーリングアサルトはレベルXIのジェムのため、使えるのはLv41から。
