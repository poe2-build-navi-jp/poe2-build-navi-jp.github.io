予算別：1点の買い足し・構成切替・完成後を分ける

「低予算○Divineなら必ず完成」と価格を固定せず、使える予算の中で何を揃えるかを決めます。相場確認は同じリーグ・同等のロール・強化状態で行い、周回用の通貨は購入予算から分けて残します。

段階使い方

切替用セットの予算装備・ジェム・ソケット品・能力値補完・振り直しを合計。1品だけ買って現行構成を崩さない。

全ビルド共通：死亡・火力・速度のどこが不足か

  • すぐ死ぬ：不足耐性、回復、ライフ／ESなど採用する防御機構の不足を先に確認。購入後に必要能力値が足りなくならないかも調べる。
  • 倒せない：主力の種類を確認。アタック武器の追加ダメージ、ミニオンレベル、スペルレベルなど、自分の主力に有効な項目を選ぶ。
  • 移動が遅い：ブーツの移動速度と移動スキルの運用を確認。2つの武器セットを使う構成では速度用と火力用を取り違えない。
  • 高いユニークが欲しい：その装備が成立させる機能を確認。今の指輪・ジェム・パッシブで機能しない品は購入を後回しにする。

よくある質問

予算はいくらあれば完成する？

リーグ・時期・ロールで価格が変わるため固定額は設定していません。今の段階を維持する買い足しと、装備・ジェム・振り直しをまとめて揃える切替予算を分けてください。

レアとユニークはどちらを先に買う？

不足する防御や能力値をレアで補い、専用構成を成立させるユニークは必要条件と一緒に準備します。高価なユニークを先に買う共通ルールはありません。

装備を替えたら弱くなったのはなぜ？

消えた耐性・能力値・Spirit、主力に有効なMod、武器セット、マナ維持を確認します。まず旧装備へ戻して差を確認し、原因を1つずつ切り分けてください。
