PoE2 リチュアル攻略｜トリビュートの使い道・恩寵の選び方・霧の王への進め方

祭壇の円で倒した敵が復活し、倒し直すとトリビュートが入ります。お告げや狙いのユニークを優先して買い、買えない品は繰り越し、余りは王に捧げて王との謁見を集めます。霧の王はティア14以上のウェイストーンで無の中核に入って挑みます。

仕組み：祭壇の円で倒した敵が復活する

リチュアルの祭壇の周りには白い円があり、円の中で倒した敵は祭壇に吸収されます。祭壇を起動すると、その敵がまとめて復活します。倒し直すとトリビュートが手に入り、これで恩寵（報酬）と交換します。[1][2]

リチュアルのあるマップには、祭壇がたいてい3〜4か所あります。同じ敵が何度も復活した場合、2回目以降のトリビュートは少しずつ減ります。[1]

トリビュートはそのマップの中だけで使えます。最後の祭壇を終えたら、マップを出る前に使い切りましょう。現在の量は経験値バーのすぐ上に表示されます。[1]

  • ボスの部屋に祭壇がある場合は、起動するとそのボスも復活します。同じマップの複数の祭壇で復活し、最後の祭壇で何体もまとめて出ることがあります。[1]
  • 祭壇の日本語の種類名はゲーム内表示で確認できていないため、英語名のまま載せています。

恩寵の選び方：買う・繰り越す・リロールする

祭壇を終えてからもう一度クリックすると、恩寵の一覧が開きます。報酬はユニーク、お告げ、通貨アイテムです。[1]

  • 優先順は、お告げか狙っているユニーク → 通貨アイテム → 余りを王へ。資料では、お告げは入手手段として効率がよく、高値で売れることもあるとしています。[1]
  • 恩寵に並ぶお告げには、補給のお告げ・再生のお告げ・偉大なる高貴なお告げ・左側／右側の消去のお告げなどがあります。[2]
  • 繰り越しの正確な費用は品物と手持ちのトリビュートで変わり、資料にも具体的な数値はありません。[1]

霧の王への進め方：王との謁見からボダックまで

リチュアルはキャンペーン中のフレイソーンで初めて出会い、そこで霧の王と戦います。エンドゲームでは、捧げたトリビュートで「王との謁見」を手に入れてから進めます。最初の1枚は比較的早く手に入ると資料にあります。[1]

  • 挑む前に、武器の更新、複数のボスに耐える防御と回復、ボスの動きの確認をすませる。ボスが1体増えるアトラスパッシブ（見えざるものを顕現させる）は、強くなるまで取らない。[1][2]
  • 資料では、このクエスト中に倒れても経験値を失わないとされています（ハードコアは通常リーグへ移動）。[1]
  • 運営者はLv91のジェムリングリージョネアでボダックを倒し、撃破後に「6リチュアルアトラススキルポイントを獲得しました」と表示されました。
  1. 恩寵の画面で余ったトリビュートを王に捧げ、バーを満たして「王との謁見」を受け取る。
  2. アトラスで3体の像に囲まれたカイル・タルス（無の中核のすぐ北）へ行き、NPCのイーファと話す。
  3. ティア14以上のウェイストーンで無の中核に入り、霧の王を倒す。1回目の撃破後、青い光を追った先で2回目の戦い（少し難しい）になる。
  4. 霧の王が落とす「王の首」をイーファへ持ち帰る。
  5. アトラスの目印をたどって人形の部品を集める。後半のマップでは、それまでのボスが復活して5〜6体まとめて出ることがある。
  6. 部品をすべてそろえると「名もなき者の儀式」が始まり、ピナクルボスのボダックに挑める。

アトラスパッシブ：まずトリビュートと繰り越しから

リチュアルのアトラスパッシブは、ポイントを振り直しにくい点に注意します。資料が勧める順番は、トリビュートの量 → 繰り越しと報酬の効率 → 王への進み → ウィスプと敵の追加 → 難しくするノード → ボス追加 → 名もなき者の儀式のノードです。[1]

  • 表は主なノードの抜粋です。ほかに、特定の種類のリチュアルが出やすくなるノードや、名もなき者の儀式を1マップ延ばすノードなどがあります。[2]

リチュアルの石板は慣れてから

リチュアルの石板はマップに祭壇を追加します（使用回数10回）。資料では、まず通常のリチュアルのあるマップを低めのウェイストーンで回してアトラスポイントと石板を集め、石板は後から使う流れを勧めています。[1][2]

  • ユニークの石板「信仰の自由」は、恩寵の価格が10〜15%上がる代わりに、リロールできる回数が2倍になります。[2]
  • 石板の効果には、リロール・繰り越し費用・お告げや王との謁見の出やすさを変えるものがあります。[1]

よくある質問

トリビュートは次のマップに持ち越せますか？

持ち越せません。マップ内でだけ使えるので、出る前に恩寵の購入・繰り越し・王への奉納で使い切ります。[1]

繰り越した恩寵は次の祭壇で必ず出ますか？

必ずではありません。数回先の祭壇で出ることがあります。アトラスパッシブ「忍耐の献身」で、再出現が50%早くなり、費用も50%減ります。[1][2]

霧の王にはどうやって挑みますか？

王との謁見を手に入れてカイル・タルスのイーファと話し、ティア14以上のウェイストーンで無の中核に入ります。[1]

何を買えばいいか迷ったら？

お告げか狙っているユニークを優先し、次に通貨アイテム、余ったトリビュートは王に捧げます。[1]
