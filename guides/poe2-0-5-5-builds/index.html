PATCH 0.5.5 / BUILD GUIDE

PoE2 0.5.5おすすめビルド一覧

編集：オカピ研究所 · 情報源・確認方法ページ更新：2026-11-13

迷ったら、初心者はミニオン、弓はアイスショット、近接は旋風強襲、SSFはエッセンスドレインから選べます。各ビルドで現在Lvを入力すると、今やること3つを確認できます。

対応：0.5.5最終確認：2026-11-11

まずやること3つ

  1. 最優先近接・遠距離・召喚など、続けたい戦い方を決める
  2. 次ビルド詳細を開いて現在Lvを入力する
  3. その次表示された「今やること」3つから進める
この記事の目次
  1. 迷ったら目的別に選ぶ
  2. 0.5.5で最初に確認すること
  3. 初心者が選ぶ基準
  4. 掲載中のビルドから選ぶ

迷ったら目的別に選ぶ

最強1位を断定するのではなく、操作方法と育成条件で4候補に絞りました。各カードから現在Lvに合う育成手順へ進めます。

0.5.5で最初に確認すること

0.5.5はForbidden Ritesイベントリーグを含む更新です。イベント開始は公式発表で2026年9月4日13時（PDT）、日本時間9月5日5時と確認しています。

掲載ビルドは対応パッチ、最終確認日、強み、弱み、8段階ロードマップを分けて表示します。固定DPSや固定相場は同条件で検証できないため掲載していません。

初心者が選ぶ基準

  • 途中で主力スキルが変わる時期を理解できるか
  • 苦手な状況や操作上の弱点を許容できるか
  • 現在Lvの段階に必要な装備・スキル・パッシブ方針を確認できるか
  • リーグスターターやSSFの表示に確認根拠があるか
