POE2 / STRATEGY GUIDE

PoE2 間幕攻略｜3地域の進め方・ボス・報酬とエンドゲーム解放

間幕はオガム・ヴァスティリ・クリアールの3地域を任意の順に進めます。各地域の最終ボス後の報告まで終えたら、キングスマーチのフードをかぶった者から特化の書を受け取り、次の移動とエンドゲーム導入を進めましょう。任意ボスの報酬は、主線の完了と分けて回収・使用を確認します。

PoE2の間幕（Interlude）をAct4クリア後から解説。オガム・ヴァスティリ・クリアールの順番、必須ルートと任意報酬、リサラ・アズマディなどのボス対策、3地域完了後のエンドゲーム移行を確認できます。

対象：0.5.5e資料確認 2026-10-09出典・確認範囲

間幕攻略の結論：3地域の協力を得て、キングスマーチで報告する

PoE2の間幕（Interlude／インタールード）は、Act4とエンドゲームの間にある3地域の物語です。オガムのエゾマイト、ヴァスティリのマラケス、クリアールのヴァールの協力を得て、キングスマーチのフードをかぶった者へ戻ります。[6][23]

地域を攻略する順番は自由です。ただし、1地域だけで全体クリアにはなりません。各地の最終ボスを倒した後の会話・報告まで終え、3地域とも主線を完了させてください。[6][7][11][17]

現在は旧Cruel難易度でAct1〜3を繰り返す進行ではありません。本記事は2026年10月9日確認、0.5.5e時点の間幕の進め方を案内します。[1][2][25]

間幕の進め方・3地域のルート早見

Act4のタヴァカイ戦後のイベントを終えたら、キングスマーチのフードをかぶった者から行き先を選びます。初めて行く地域では、拠点NPCに話してその地域の主線を確認しましょう。[7][11][17]

  • オガム：避難所 → 焼け焦げた農場 → セールの巨石群 → 農場の闇へ戻る → ブラックウッド → ホルテン → ホルテンの豪邸 → レンリーへ報告。[7][8]
  • ヴァスティリ：カーリバザール → カーリの渡り路 → カタールのプール → セル・カーリの聖域 → 渡り路へ戻る → ガライの門 → キーマ → キーマの貯水池 → グランドバリャとジャド。[11][12]
  • クリアール：森の広場 → 灰の森 → クリアール村 → 氷河の湖 → クリアール山山頂 → 侵蝕の峡谷 → クアチクの地下避難所 → ドリヤニを呼んで会話。[17][19]
  • 3地域完了後：キングスマーチ → フードをかぶった者の報酬 → 特化の書を使用 → オリアスへの移動を選ぶ → ジグラットの避難所でエンドゲーム導入。[23]

どの間幕から進める？不足している強化で選ぶ

全員共通の固定最適順はありません。地域のレベルは間幕の進行に応じて上がるため、後回しにすれば必ず低レベルのまま残るわけでもありません。[6]

編集上のおすすめは、スピリット不足ならクリアール村のリサラを先に目指すこと。最大スピリット+40が、その後の持続スキルやミニオン構成を組み直す助けになります。リサラに勝てない時は固執せず、他地域の報酬と装備更新を挟みましょう。[18]

  • ライフを補いたい：ヴァスティリのカーリの渡り路で、マグマの神殿の最大ライフ5%増加を候補にする。[13]
  • パッシブを補いたい：オガムのオスウィン、ヴァスティリの道を掃討、クリアールの吠える風。いずれも主線と別に確認したい2ポイント報酬。[9][13][20]
  • 編集上の管理方法：各地域を「最終ボス未撃破／撃破後の会話待ち／主線完了」に分ける。任意報酬はさらに「取得済み／使用済み」で確認する。

オガム前半：農場の闇はセールの巨石群を経由して開ける

避難所のレンリーに話し、焼け焦げた農場へ。イソルデとヘルドラを倒しても、農場の闇はそのまま通過できません。セールの巨石群に向かい、ルーンの刻まれたメガリスを起動して祭壇へ進むのが主線です。[7]

霧の刃、シオラを倒したら、ウーナの到着を待って会話します。その後、焼け焦げた農場の闇へ戻り、ブラックウッドに入ってください。セールの巨石群の奥に次の地域の出口を探し続けないことがポイントです。[7]

  • シオラ対策案：暗くなったら発光する巨石を目指して視界を戻す。暗闇の中で攻撃を続けるより、まず戦う床を見える状態にする。[10]
  • ブラックウッドではホルテンへの入口を探す。闇のお告げなどの寄り道を全回収することは、豪邸へ向かう主線の条件ではありません。[8]

オガム後半：豪邸の2体を倒し、避難所のレンリーへ

ホルテンからホルテンの豪邸へ向かい、ウルフリック族長とエルズウィス婦人を倒します。クエスト文の「ホルテン邸」は同じ行き先です。撃破後は避難所へ戻ってレンリーに報告し、エゾマイトの主線を終えましょう。[7][8]

  • 豪邸ボス対策案：片方が倒れると残った相手の攻撃が強化されます。倒す直前に回復と立ち位置を整え、残った1体への反撃を急がない。[10]
  • 骨の檻に閉じ込められたら壁を壊して脱出する。檻の中へ降る攻撃を、通常の移動だけで避けようとしない。[10]
  • ホルテンにいるシグベルトとゴッドウィンは寄り道。主線の豪邸ボスとは別なので、彼らを倒しただけでこの地域を完了扱いにしない。[8]

オガムの任意報酬：狼の砦で看守の帳簿を使う

ホルテンから狼の砦へ入り、恐怖の看守、オスウィンを倒すと、看守の帳簿で武器セットパッシブスキルポイント2を得られます。主線の進行先は豪邸ですが、初回攻略では回収を勧めたい寄り道です。[9]

  • オスウィン対策案：回転攻撃から距離を取り、地面の棘の予兆を優先して避ける。ボスの背後へ回る時も、残った氷の棘で逃げ道を塞がれていないか確認する。[10]
  • 編集上の確認：拾った帳簿を使い、パッシブ画面に未配分ポイントが増えたかを見る。撃破済みアイコンだけで報酬受領済みと判断しない。

ヴァスティリ前半：案内を使って聖域へ、アサラの会話まで進める

カーリバザールでアサラとザーカに話し、カーリの渡り路へ。アブ・ビナイの塔とウェイファインダーを利用して案内を追い、カタールのプール（クエスト文ではカタールの池）からセル・カーリの聖域へ向かいます。[11]

聖域のコブラの王、エルザラを倒したらアサラに話します。次はカーリの渡り路側からガライの門へ。聖域とガライの門は別方向の枝なので、聖域のボス部屋の先だけを探し続けないでください。[11][12]

  • エルザラ対策案：移動する竜巻や炎をまとった障害物を避け、追尾する砲撃中は同じ場所で攻撃し続けない。安全な床に移ってから反撃する。[16]
  • 聖域の「2つの願い」は任意の装備報酬です。ユーンとランギーンのバリャを用いる寄り道と、主線で探すグランドバリャを混同しない。[12]

ヴァスティリの任意報酬：ライフ5%と道を掃討の2ポイント

カーリの渡り路のマグマの神殿では、モルテンワンの贈り物を使うと最大ライフが5%増加します。ライフの固定値+5でも、ライフ回復量の増加でもありません。[13]

同じ渡り路のアクティとアナンドルは、任意クエスト「道を掃討」の対象です。2体を倒した後、カーリバザールのリスに戻って特化の書を受け取り、使用すると武器セットパッシブスキルポイント2を得られます。[13][14]

  • 編集上の進め方：渡り路を探索中に寄り道を済ませ、カタールのプールとガライの門で見つけたウェイポイントを登録しておく。広い渡り路の再探索を減らしやすい。[12]

ヴァスティリ後半：ガライの門からキーマの貯水池へ

ガライの門で邪悪な炎、ヴォルナスを倒し、キーマへ入ります。墓地を探してジャドを呼び、会話を終えてキーマの貯水池へ進んでください。[11]

貯水池の最終ボスはファリドゥンの王子、アズマディです。撃破だけで帰還せず、グランドバリャに触れ、ジャドとの会話まで終えるとマラケスの主線が完了します。[11]

  • ヴォルナス対策案：最初の叩きつけだけを避けて攻撃に戻らず、続く連撃と残る床からも離れる。[16]
  • アズマディ対策案：投げた剣の往復、瞬間移動後の追撃、連続突進が終わるまで短い回避を優先。時間の泡に捕まっている時に長い攻撃動作を始めない。[16]
  • 編集上の立て直し：連撃途中で毎回被弾するなら、攻撃回数を減らして一連の動きを観察する。必要DPSやライフを固定値で決めず、回避後に確実に当てられる攻撃を選ぶ。

キーマの七本の柱：同時取得ではなく、自分に合う恩恵を選ぶ

七本の柱は任意の恒久強化を選ぶ場所です。選択は後で戻って変更できます。全てを順番に触れば全部の効果が重なる、という報酬ではありません。[12][15]

  • タバナ：全ての元素耐性+5%。オルバラ：移動スピード3%増加。コチャイ：全ての能力値+5。[15]
  • アーケリ：グローバルのアーマー・回避力・エナジーシールド15%増加。ハラニ：クールダウン解消レート12%増加。ガライ：存在下の効果範囲20%増加。[15]
  • アリマ：獲得経験値5%増加と引き換えに、耐性・移動速度・能力値などが下がる選択。経験値だけ見て選ばないでください。[15]
  • 編集上の選択案：防御が不安なら不足している耐性を、装備やジェムの要件が足りないなら能力値を候補にする。ガライの存在下の効果範囲は、全攻撃スキルの範囲増加として数えない。

クリアール前半：リサラを倒してスピリット+40を回収

森の広場のドリヤニに話し、灰の森からクリアール村へ進みます。村の主線ボスは放浪の槍、リサラです。クエスト目標では「錯乱したアズメリ」と表示される段階もあります。[17][18]

リサラの報酬、ジェムに覆われた頭蓋骨は最大スピリット+40を付与します。倒したら頭蓋骨の回収と使用を確認してから氷河の湖へ。スピリットを増やしても、追加の持続スキルが自動で有効になるとは限らないので、使用中の構成も見直しましょう。[18]

  • リサラ対策案：槍投げ後に残る嵐と毒の床を避け、動ける足場を保つ。ウィスプは起動するとボスを強化するため、避ける時も不用意に触れない。[22]
  • 編集上の立て直し：長期戦で足場が足りなくなるなら、主力スキルのレベル・適合するサポート・武器を見直す。火力だけを求めて全ての防御を捨てる必要はない。

クリアール中盤：氷河の湖から山頂と侵蝕の峡谷へ

氷河の湖では凍てつく鉤爪、ラッカーを倒し、クリアール山山頂へ登ります。その先の侵蝕の峡谷では守護者、ストームゴアを倒してクアチクの地下避難所へ進みます。山頂に着いただけでは主線完了ではありません。[17][19]

  • ラッカー・ストームゴア対策案：ラッカーの冷気攻撃、ストームゴアの跳躍叩きつけと雷のなぎ払いを警戒。大きな攻撃動作の正面から離れ、追撃を確認してから反撃する。[22]
  • ラッカーを特定の攻撃中にパリィすると一部ダメージが無効になる不具合は、0.5.5cで修正されています。異常な挙動を古い攻略の必須ギミックだと思い込まないでください。[5]
  • 灰の森の古代のモニュメント、山頂の長老マドックスの贈り物は任意の寄り道。主線のボス討伐やNPC報告とは別に回収を判断できます。[19]

クリアールの任意報酬：吠える洞窟の氷の牙をヒルダへ

吠える洞窟は氷河の湖から入る寄り道です。アボミネーションのイエティを倒し、氷の牙を拾って森の広場のヒルダへ届けます。報酬の特化の書を使うと、武器セットパッシブスキルポイント2を得られます。[20][21]

  • 編集上の確認順：イエティ撃破 → 氷の牙を取得 → ヒルダへ報告 → 特化の書を受領 → 使用。洞窟のボスを倒しただけでポイントが付いたと考えない。
  • 洞窟を出た後は、氷河の湖の主線に戻ってラッカーと山頂を目指します。吠える風の完了は、ヴァールの主線完了とは別です。[17][20][21]

クリアール最終ボス：ゾリンとゼリナの後はドリヤニを呼ぶ

クアチクの地下避難所で血の司祭、ゾリンと血の巫女、ゼリナを倒します。その場でドリヤニを呼び、会話を済ませるとヴァールの協力を得られます。最終ボス部屋から即帰還して会話を飛ばさないでください。[17][19]

  • 対処案：ゼリナの赤い円から離れ、追い打ちの連撃を避ける。被弾は相手のライフ回復にもつながるため、攻撃を受けながら削り合う形を避ける。[22]
  • ゾリンの祭壇ビームと動く血の池を見ながら、2体を視界に入れる。回復が見えた時も無理に張り付かず、次に逃げる方向を確保する。[22]

ビーコンやリチュアルは主線の完了条件と分ける

0.5.0でFate of the Vaalがコア入りし、Act3に続く2組目の古代ビーコン6個が間幕に配置されています。ビーコンを使う寺院コンテンツと、3勢力を仲間に加える主線は別に確認しましょう。[3][7][11][17]

Forbidden Ritesでは各間幕にボスリチュアルの連続遭遇があり、前のボスが次の遭遇へ加わります。通常のボス紹介より敵が多い時は、イベントリーグの要素かを確認してください。この追加要素を全リーグ共通の間幕ルートとしては扱いません。[4]

編集上の進め方：まず主線の行き先と報告先を把握し、装備更新に役立つ寄り道を足す。マップ上の全アイコンを消すことと、次章へ進めることを分けると迷いにくくなります。

間幕クリア後：特化の書を使い、エンドゲーム導入へ

3勢力の主線が終わったらキングスマーチへ戻り、フードをかぶった者に話します。「オリアスの包囲」の報酬である特化の書を受け取り、使用してから次の移動へ進みましょう。全間幕完了の報酬は武器セットパッシブスキルポイント2です。[23][24]

会話ではオリアスへの移動を選びますが、その後の導入で到着するのはジグラットの避難所です。ここでドリヤニの説明を進め、マップデバイスとウェイストーンを使うエンドゲームへ移行します。[23]

間幕の解放・完了条件を「レベル65になるだけ」と覚えないでください。公式のレベル65という説明は間幕導入時の到達目安であり、現在地で止まったらまず3地域の主線と報酬・移動の会話を確認します。[2][23]

  • エンドゲーム開始後の案内は別記事へ：0.5.0以降、最初の塔の完了でFortressが現れ、その内部のマップがAtlasポイントの取得先です。旧来の一定枚数のマップ消化を、間幕クリアや現在のAtlasポイントの条件に混ぜないでください。[3]
  • 出発前チェック：看守の帳簿／リスの特化の書／ヒルダの特化の書／リサラの頭蓋骨／モルテンワンの贈り物／キーマの恩恵／全地域完了の特化の書。必要な報酬の使用・選択まで済んでいるか確認する。[9][13][14][15][18][21][23]

よくある質問

間幕はどの順番で進めればいい？

3地域は任意順です。スピリットを増やしたいならクリアール村のリサラ、ライフを補いたいならカーリの渡り路の任意報酬を候補にできます。固定の最適順ではなく、現在の不足で選びましょう。[6][13][18]

Act4をクリアしたのにエンドゲームに行けないのはなぜ？

Act4後に3地域の間幕が残っています。各地域の最終ボス後の会話まで完了し、キングスマーチのフードをかぶった者へ戻ってください。[7][11][17][23]

農場の闇を通れない。シオラを倒した後はどこへ行く？

ウーナの到着を待って会話し、焼け焦げた農場の闇へ戻ります。セールの巨石群の奥に新しい出口を探す進行ではありません。[7]

ガライの門やキーマへ進めない時は？

先にカタールのプールからセル・カーリの聖域へ行き、エルザラ撃破後のアサラとの会話を確認。キーマではジャドを呼んで話す段階も必要です。現在のクエスト目標に沿って戻り先を決めてください。[11]

リサラを倒したのにスピリットが増えない時は？

ジェムに覆われた頭蓋骨の回収と使用を確認してください。クリアール村の報酬は最大スピリット+40です。別地域の完了報酬ではありません。[18]

ボスを倒したのにパッシブポイントが増えないのはなぜ？

オスウィンは看守の帳簿の使用、アクティとアナンドルはリスへの報告、イエティは氷の牙をヒルダへ渡す手順があります。報酬アイテムの受領・使用まで確認しましょう。[9][14][21]

間幕の任意ボスやビーコンは全部クリア必須？

全探索は主線の条件ではありません。狼の砦、道を掃討、吠える風などは任意報酬として扱い、エゾマイト・マラケス・ヴァールの主線とは分けて確認します。[7][9][11][14][17][21]

間幕クリア後の行き先がオリアスではなくジグラットなのは正常？

クエスト上はオリアスへ向かう選択ですが、その後はジグラットの避難所へ到着する導入です。フードをかぶった者の報酬と会話を済ませ、到着後のドリヤニの案内を進めてください。[23]

このページに出てくる用語

  • DPS：1秒あたりに与えるダメージ（Damage Per Second）の目安。
  • サポートジェム：スキルジェムにはめて、そのスキルの効果を強めたり変えたりするジェム。
  • パッシブツリー：レベルアップなどで得たポイントを振って、能力や効果を取る巨大なツリー。
  • 耐性：火・冷気・雷・混沌ダメージを割合で減らす防御。上限は通常75%。
  • Endgame：キャンペーンを終えた後に遊ぶ、Atlas（アトラス）でのマップ攻略と強敵との戦い。
  • Spirit：常駐バフ・永続ミニオン・自動発動用ジェムを動かすために予約する力。
  • エナジーシールド：ライフより先にダメージを受け止め、ESを失わない状態が続くと自動で回復する防御。
