PoE2はどうやって始める？無料化後の始め方

Path of Exile 2は2026年12月11日（PST）の正式版1.0から基本プレイ無料になる予定です。PC（Steam・Epic Games Store）、PS5、Xbox Seriesで遊べると発表されており、正式版以降は各ストアから無料で入手できます。

対応：0.5.5最終確認：2026-09-28

まずやること3つ

  1. 最優先遊ぶ機種（PC・PS5・Xbox Series）を決める
  2. 次12月11日以降に各ストアから無料で入手する
  3. その次4問の職業診断で最初の職業を決めておく

対応機種と入手先

正式版1.0は、PlayStation 5、Xbox Series、PC（SteamとEpic Games Store）で2026年12月11日に公開予定と報じられています（Grinding Gear Gamesの発表に基づく報道）。

アーリーアクセス開始時は、Steam・Epic Games Storeに加えて公式のスタンドアロン版PCクライアントでも配信されていました（公式FAQ）。

今と12月11日以降の違い

  • 現在：アーリーアクセス中のため、Steamではサポーターパックの購入が必要です。
  • 12月11日以降：アーリーアクセス終了後は基本プレイ無料になると、公式発表とSteamストアに記載されています。
  • 無料化を待つか今から始めるかは、1.0を待たずに操作に慣れたいかどうかで決めてください。現在の0.5.5の育成手順が1.0でも同じとは限りません。

始めるまでの手順

正式版でのアカウント作成手順の詳細は、公開時に公式の案内を確認してから追記します。

  • 遊ぶ機種を決める。PCの場合は、必要スペック・推奨スペック（Windows 10、DirectX 12、空き容量100GB、VRAM 3GB以上など）を確認する。
  • 12月11日以降、Steam・Epic Games Store・PlayStation Store・Microsoft Storeから入手する。
  • 公式サイトのニュース登録（pathofexile2.com/register）で、公開日や変更のお知らせを受け取れる。
  • 最初の職業を決めておく。迷う場合は4問の職業診断で候補を絞る。

機種をまたいで遊べる？

  • PC・PS5・Xbox Seriesの間でクロスプレイでき、同じパーティーで遊べます。
  • 同じアカウントでログインしていれば、キャラクターの進行とアイテムは機種間で引き継がれます。
  • 課金アイテムは、PlayStationで購入したものはPlayStation専用です。PC版とXbox版の間では共有されます。

まだ公式に確認できていないこと

ExileCon 2026（11月7〜8日）などの公式発表を確認し、確認できたものから追記します。

  • アーリーアクセスのキャラクター・リーグが1.0でどう扱われるか
  • 正式版でのMac対応（公式FAQではアーリーアクセス開始時は非対応。現在のSteamストアにはmacOSの動作環境が掲載されています）や、スタンドアロン版PCクライアントの扱い
  • 正式版のアカウント作成・連携の具体的な手順

よくある質問

PoE2は無料で遊べる？

正式版1.0（2026年12月11日公開予定）から基本プレイ無料です。現在のアーリーアクセス中は、Steamではサポーターパックの購入が必要です。

どの機種で遊べる？

正式版はPC（Steam・Epic Games Store）、PS5、Xbox Seriesで公開予定と報じられています。

機種をまたいで遊べる？

PC・PS5・Xbox Seriesの間でクロスプレイでき、同じアカウントなら進行を引き継げます。
