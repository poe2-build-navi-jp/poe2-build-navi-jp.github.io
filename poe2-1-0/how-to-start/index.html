PoE2はどうやって始める？無料化後の始め方

Path of Exile 2は、2026年8月25日の公式発表で、12月11日（PST）に正式版として基本プレイ無料で公開予定と案内されています。各ストアでの最終的な入手・アカウント作成手順は未確認のため、公開時の公式案内と利用するストアの表示を確認してください。

対応：0.5.5最終確認：2026-10-06

まずやること3つ

  1. 最優先遊ぶ機種（PC・PS5・Xbox Series）を決める
  2. 次公開予定日の12月11日前後に、公式案内と利用するストアで入手方法を確認する
  3. その次4問の職業診断で最初の職業を決めておく

対応機種と入手先

正式版1.0は、PlayStation 5、Xbox Series、PC（SteamとEpic Games Store）で2026年12月11日（PST）に公開予定と報じられています（Grinding Gear Gamesの発表に基づく報道）。

アーリーアクセス開始時は、Steam・Epic Games Storeに加えて公式のスタンドアロン版PCクライアントでも配信されていました（公式FAQ）。

今と12月11日以降の違い

  • 現在：アーリーアクセス中のため、早期アクセス権が必要です。通常は対象サポーターパックで入手できますが、付与済みのアクセス権や有効なキーでも参加できます。
  • 12月11日以降：アーリーアクセス終了後は基本プレイ無料になると、公式発表とSteamストアに記載されています。
  • 無料化を待つか今から始めるかは、1.0を待たずに操作に慣れたいかどうかで決めてください。現在の0.5.5の育成手順が1.0でも同じとは限りません。

始めるまでの手順

正式版でのアカウント作成手順の詳細は、公開時に公式の案内を確認してから追記します。

  • 遊ぶ機種を決める。PCの場合は、必要スペック・推奨スペック（Windows 10、DirectX 12、空き容量100GB、VRAM 3GB以上など）を確認する。
  • 正式版の公開時に、利用するプラットフォームの公式案内とストア表示で、入手・インストール方法を確認する。各ストアの最終手順は未確認。
  • 公式サイトのニュース登録（pathofexile2.com/register）で、公開日や変更のお知らせを受け取れる。
  • 最初の職業を決めておく。迷う場合は4問の職業診断で候補を絞る。

機種をまたいで遊べる？

  • PC・PS5・Xbox Seriesの間でクロスプレイでき、同じパーティーで遊べます。
  • 遊ぶプラットフォームを連携し、同じサブアカウントを選ぶと、キャラクターの進行とアイテムを引き継げます。アーリーアクセス中は、各プラットフォームのアクセス権も必要です
  • PlayStationで購入した課金アイテムは他機種では使えず、PC・Xboxで購入したものもPlayStationでは使えません。PC版とXbox版では、購入した同じサブアカウントで共有できます

まだ公式に確認できていないこと

ExileCon 2026（11月7〜8日）などの公式発表を確認し、確認できたものから追記します。

  • 1.0での最終的なキャラクター・リーグ移行手順。既存の公式FAQでは、キャラクターを消去せず正式版Standardとは別のEarly Accessリーグに残す方針です
  • 正式版でのMac対応（公式FAQではアーリーアクセス開始時は非対応。現在のSteamストアにはmacOSの動作環境が掲載されています）や、スタンドアロン版PCクライアントの扱い
  • 正式版のアカウント作成・連携の具体的な手順

よくある質問

PoE2は無料で遊べる？

正式版1.0（2026年12月11日・PST公開予定）から基本プレイ無料です。現在のアーリーアクセス中は、早期アクセス権が必要です。通常は対象サポーターパックで入手できますが、付与済みのアクセス権や有効なキーでも参加できます。

どの機種で遊べる？

正式版はPC（Steam・Epic Games Store）、PS5、Xbox Seriesで公開予定と報じられています。

機種をまたいで遊べる？

PC・PS5・Xbox Seriesの間でクロスプレイでき、プラットフォームを連携して同じサブアカウントを選べば進行を引き継げます。
