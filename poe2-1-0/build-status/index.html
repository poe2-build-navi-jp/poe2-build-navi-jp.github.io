「1.0で確認済み」にする基準

次のすべてを確認できたビルドだけを「1.0で確認済み」にします。1つでも確認できない場合は確認待ちのままです。

  • 主力スキルとサポートジェムが1.0に存在し、名前と解禁Lvが一致する
  • アセンダンシーと主要なパッシブが削除・大幅変更されていない
  • 必須のユニークや装備条件、SSFでの成立可否が元ガイドと一致する
  • 元ガイドが1.0対応と明記している

「1.0最強ビルド」を載せない理由

1.0の公開直後は、公式パッチノートと実際のプレイ結果がそろうまで、各ビルドの強さを判断できません。本サイトは予想のランキングを確定情報のように載せず、確認できたものから順に更新します。

確認の順番

1.0対応の元ガイド（Maxroll・Mobalyticsなど）が出たビルドから、1本ずつ確認します。大きく変わって元ガイドが見つからないビルドは、掲載を見直します。

よくある質問

PoE2 1.0のおすすめビルドは？

1.0で確認できたビルドから順に、このページで「確認済み」として案内します。確認前のビルドの強さは断定しません。

0.5.5のビルドは1.0でもそのまま使える？

確認できるまで断定できません。スキル名・解禁Lv・装備条件が変わっている可能性があるため、確認できたものから順に更新します。
