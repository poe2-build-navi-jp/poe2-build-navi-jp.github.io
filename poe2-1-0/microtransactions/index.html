POE2 1.0 / SHOP

PoE2の課金はどれを買えばいい？

PoE2は正式版1.0から基本無料で、課金しなくても遊べます。課金アイテムは見た目の装飾と、アイテムを整理・出品するスタッシュタブが中心です。海外の主要ガイドでは、最初に買うならCurrency Tab（通貨タブ）が勧められています。

対応：0.5.5最終確認：2026-10-06

まずやること3つ

  1. 最優先まずは課金せずにキャンペーンを遊ぶ
  2. 次最初に買うならCurrency Tab（通貨タブ）を検討する
  3. その次スタッシュタブはセールを待ってから買う

課金しないと遊べない？

  • 正式版1.0は基本プレイ無料です。
  • 開発元は、PoE2を「pay to win（課金で強くなる）」にはしないと述べていると報じられています。
  • 課金アイテムは、見た目の装飾（コスメ）と、収納・整理・出品を便利にするスタッシュタブが中心です。必要なタブは、遊び方や集まるアイテムに応じて選びます

最初に買うならどのスタッシュタブ？

優先順位はMaxrollのスタッシュタブ解説（2026年5月更新、0.5時点）に基づきます。価格は変わることがあるため、購入前に公式ショップで確認してください。

  • Currency Tab（通貨タブ）：大量に拾う通貨をまとめて整理できるため、最優先で勧められています。
  • Map Stash Tab（マップタブ）：Endgameで使うWaystoneをTier別に整理するためのタブです
  • 公開設定にできるPremium系のタブは取引サイトへの掲載に使います。Merchant's Tabは、AngeのAct 4のクエストを終えると使える非同期取引用のタブです。通常のタブには公開出品機能がありません

買う前に知っておきたいこと

  • スタッシュタブは、大型アップデートの直後などにセールで割引されることが多いと案内されています。
  • どのタブが必要かは、遊んで何がたまるかを見てから決めても遅くありません。
  • 取引をしないなら、出品用のタブは急いで買う必要はありません。

PoE1で課金した人は？（公式アーリーアクセスFAQ）

これはアーリーアクセス時点の公式FAQの内容です。1.0で変更がないか、公開時に確認します。

  • PoE1のアカウントでそのままPoE2を遊べます。
  • PoE1で買ったスタッシュタブは、PoE2に関係するものは使えます。リーグ専用のタブなど、PoE2にない内容のタブは使えない場合があります。
  • PoE1の見た目アイテムは順次対応中で、まだ使えないものもあります。

機種ごとの注意

  • PlayStationで購入した課金アイテムは他機種では使えず、PC・Xboxで購入したものもPlayStationでは使えません。PC版とXbox版では、購入した同じサブアカウントで共有できます
  • スタッシュタブを持っていない機種でログインすると、そのタブは取り出し専用になります（公式FAQ）。

まだ確認できていないこと

公式の案内を確認できたものから追記します。

  • 正式版1.0での課金アイテムの価格やショップ内容の変更
  • 無料化にあたって、アーリーアクセス購入者に特別な扱いがあるか
  • 公式FAQの内容が1.0で変わるかどうか
