POE2 1.0 / SYSTEM REQUIREMENTS

PoE2の必要スペック・推奨スペックは？

Steamストアの記載では、PoE2の最低動作環境はWindows 10、メモリ8GB、VRAM 3GB以上のGPU（GeForce GTX 960 3GBなど）、空き容量100GBです。推奨はメモリ16GB、GeForce RTX 2060クラス、SSDです。いずれも現在のアーリーアクセス版の記載で、1.0で変わる可能性があります。

対応：0.5.5最終確認：2026-09-28

まずやること3つ

  1. 最優先空き容量100GB（できればSSD）を確保する
  2. 次GPUのVRAMが3GB以上あるか確認する
  3. その次足りなければPS5・Xbox Seriesでのプレイも検討する

PCの最低動作環境（Windows）

  • OS：Windows 10
  • CPU：Intel Core i7-7700 または AMD Ryzen 5 2500X
  • メモリ：8GB
  • GPU：NVIDIA GeForce GTX 960（3GB）、Intel Arc A380、または Radeon RX 470
  • DirectX：バージョン12
  • ネットワーク：ブロードバンド接続
  • ストレージ：100GBの空き容量
  • 備考：VRAM 3GB以上のGPUが必須

PCの推奨動作環境（Windows）

  • OS：Windows 10
  • CPU：Intel Core i5-10500 または AMD Ryzen 5 3700X（Steamストアの表記のまま。同名の実在製品はRyzen 7 3700X）
  • メモリ：16GB
  • GPU：NVIDIA GeForce RTX 2060、Intel Arc A770、または Radeon RX 5600 XT
  • DirectX：バージョン12
  • ネットワーク：ブロードバンド接続
  • ストレージ：100GBの空き容量
  • 備考：SSDを推奨

Macの動作環境（Steamストア掲載）

現在のSteamストアにはmacOSの動作環境も掲載されています。ただし公式FAQでは、アーリーアクセス開始時点ではMac非対応とされていました。正式版1.0でのMac対応は、公式発表で改めて確認してから追記します。

  • 最低：macOS 10.13、2.6GHzクアッドコア Intel Core i7、メモリ8GB、Radeon Pro 450
  • 推奨：macOS 10.13、2.6GHzヘキサコア Intel Core i7、メモリ16GB、Radeon Pro 555X、SSD推奨

見落としやすい点

  • VRAM（GPUのメモリ）が3GB未満のGPUでは、最低動作環境を満たしません。
  • 空き容量は100GB必要です。SSDが推奨されています。
  • オンライン専用のため、ブロードバンド接続が必要です。
  • 上記は現在のアーリーアクセス版の記載です。1.0公開時に変更がないか確認して更新します。

自分のPCの確認方法（Windows）

  • CPUとメモリ：「設定」→「システム」→「バージョン情報」で確認できます。
  • GPUとVRAM：「dxdiag」を実行し、「ディスプレイ」タブで確認できます。
  • 空き容量：エクスプローラーの「PC」で、インストール先ドライブの空き容量を確認します。

日本語とコントローラー（Steamストアの記載）

  • 対応言語に日本語があります。音声のフル対応は英語のみです。設定方法は日本語対応のページで確認できます。
  • フルコントローラー対応で、DualShock・DualSenseにも対応しています。操作の詳細はコントローラーのページで確認できます。

スペックが足りない場合

正式版1.0はPS5とXbox Seriesでも公開予定です。PC・PS5・Xbox Seriesの間でクロスプレイでき、同じアカウントなら進行を引き継げます。詳しくは始め方のページで確認できます。
