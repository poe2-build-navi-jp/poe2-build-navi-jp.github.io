PoE2初心者向け職業・クラス診断｜4問でおすすめを絞る

プレイスタイルに合わせて、PoE2で始めやすい職業候補を4問で絞ります。診断後は、その職業のおすすめビルドと育成ページへ進めます。

Q1 どんな戦い方が好き？
Q2 何を重視する？
Q3 操作量は？
Q4 好きなテーマは？

MATCHED CLASSES

あなたと一致する候補

同点は順位を断定せず並べています。パッチ上の強さ・Tierを示す診断ではありません。

この診断の決め方

戦い方、重視点、操作量、テーマの一致度から、現在ビルドを掲載している職業を最大3件に絞ります。装備価格や一時的な火力だけでは判定しません。

強さランキングではない理由

PoE2の強さはパッチ、装備、プレイ状況で変わります。この診断は「初心者が続けやすい戦い方」を選ぶための入口です。

近接・遠距離・魔法・召喚の違い

  • 近接：敵の近くで武器や盾を使う
  • 遠距離：弓やクロスボウで距離を保つ
  • 魔法：元素・混沌などの呪文を使う
  • 召喚：ミニオンや相棒と戦う

診断後の進み方

  1. 結果から職業ページを開く
  2. 掲載ビルドを選ぶ
  3. 現在Lvを入力する
  4. 今やること3つを確認する

診断結果に出る8職業の特徴

診断の候補になる職業と、掲載中のビルドです。結果を見る前に、気になる職業の特徴を確認することもできます。

モンク：素早く間合いを変えて戦う近接タイプ

クォータースタッフや素手の攻撃を使い、接近と離脱を繰り返して戦う職業です。掲載中のビルドでは、移動を兼ねる攻撃で敵へ近づきます。

戦い方：近接・素早い操作。注意：敵へ近づくため、攻撃だけでなく回避と防御の確認も必要です。

掲載ビルド：ワーリングアサルト・マーシャルアーティスト

マーセナリー：クロスボウや武器切替を使う遠距離タイプ

クロスボウを扱い、状況に応じた攻撃や武器セットの切替を使う職業です。掲載中のビルドでは、ツイスターを中心に育成します。

戦い方：遠距離・武器切替。注意：武器セットや必要能力の確認項目が、単一武器の構成より多くなります。

掲載ビルド：ツイスター・ジェムリング、グレネード・ジェムリング

ウォリアー：盾や重い一撃で正面から戦う近接タイプ

メイスや盾を使い、敵の攻撃を受け止めながら近距離で戦う職業です。掲載中のビルドでは、シールドウォールを攻撃と防御の軸にします。

戦い方：近接・防御重視。注意：攻撃速度や移動の感覚は、素早い近接職とは異なります。

掲載ビルド：シールドウォール・スミス

ソーサレス：呪文と元素を扱う魔法タイプ

離れた位置から呪文を使うことを得意とする職業です。掲載中のビルドでは、砂と炎に関係する召喚物へ指示を出して戦います。

戦い方：魔法・召喚。注意：掲載中ビルドは、召喚物を出すだけでなく指示スキルの操作が必要です。

掲載ビルド：砂と炎のヴァラシュタ、スパーク・ストームウィーバー

ハントレス：槍で近距離と遠距離を使い分けるタイプ

槍を使い、近距離と遠距離の攻撃を組み合わせられる職業です。掲載中のビルドでは、相棒を主力にして育成します。

戦い方：近接・遠距離・相棒。注意：育成途中で主力や装備方針が切り替わる段階があります。

掲載ビルド：相棒スピリットウォーカー、ツイスター・スピリットウォーカー

レンジャー：弓で距離を保って戦う遠距離タイプ

弓を使い、移動しながら遠距離から攻撃する職業です。掲載中のビルドでは、アイスショットを主力にします。

戦い方：遠距離・素早い操作。注意：敵に囲まれない位置取りと、序盤の防御確認が必要です。

掲載ビルド：アイスショット・デッドアイ

ウィッチ：ミニオンや呪文を扱う召喚・魔法タイプ

ミニオンや呪文を使って戦う職業です。掲載中のビルドでは、ミニオンに攻撃を任せて自分は位置取りへ集中します。

戦い方：召喚・魔法。注意：ミニオンの維持だけでなく、自分自身の防御も忘れずに整える必要があります。

掲載ビルド：スナイパーミニオン・インファーナリスト、ED・コンテージョン リッチ

ドルイド：自然の力と変身を扱うプライマルタイプ

プライマルスキルやタリスマンによる変身を扱う職業です。掲載中のビルドでは、植物系スキルを主力にします。

戦い方：魔法・変身。注意：ドルイド全体には変身もありますが、掲載中の植物ビルドは変身を主軸にしていません。

掲載ビルド：植物オラクル
