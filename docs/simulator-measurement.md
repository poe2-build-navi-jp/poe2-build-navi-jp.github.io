# シミュレーターの利用状況

GA4の探索で「目標到達プロセス」を作り、以下を順に指定する。人数で比較し、イベント回数をそのまま利用者数としない。導入前のデータには遡及しない。広告ブロック・通信状況等で未送信になることがある。

| 段階 | イベント | 意味 |
| --- | --- | --- |
| 入口 | simulator_entry_click | 記事・トップ等から起動リンクを押した |
| 起動成功 | simulator_ready | 計算エンジンの起動と最初の計算が完了 |
| 育成引継 | simulator_stage_apply | 記事のLvと選択した主力で新しい試作を開始 |
| 比較 | simulator_compare_preview | 装備を保存・反映せずに比較した |
| 反映 | simulator_equipment_apply | 装備を反映／取り外した |
| 保存 | simulator_save | 端末保存または保存ファイル書き出し |
| 共有 | simulator_share_create / simulator_share_copy | URLを生成／クリップボードへコピー |
| 名前付き保存 | simulator_named_save | 構成を新規保存／更新した（actionと件数のみ） |
| 構成比較 | simulator_plan_compare | A・Bを共通の敵条件で計算した |
| 見本の取り込み | simulator_example_apply | 操作サンプル／記事の装備を内容確認後に取り込んだ |

保存のmethodはdevice/file。起動元はsource_type（入口）またはsource（起動完了）。共有構成は自分用保存を押すまで端末構成を上書きしない。メモは共有URLに含まれない。

起動成功は、構成を開いて最初に計算が成功したときに1回だけ記録する。初回の計算失敗は含めず、その後の再計算で初めて成功した場合はその時点で記録する。以後の装備・Lv変更では起動成功を重複計上しない。

共有URL・装備の本文・メモ・ユーザー名・能力値そのものは独自イベントに送信しない。シミュレーターのpage_locationはパスまでに限定する。shared=構成の表示に成功したことを示し、本人の保存構成に取り込まれたこととは区別する。

比較する指標：起動成功率、起動者の比較利用率、比較した人の保存率。低い段階に対応する画面を改善する。実数はGA4の計測開始後に確認する。

名前付き構成の名前・メモ・保存本文はイベントに含めない。見本は公開データのexample_idとkindのみ。from=recordの起動元はrecordとして記録する。見本を確認しただけの操作と「この内容で試す」で取り込んだ操作は区別する。
