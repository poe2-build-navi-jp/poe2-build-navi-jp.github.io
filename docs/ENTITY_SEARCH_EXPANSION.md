# 名前から探す・スキル装備参照

## 検索意図とURL
- `/name-index/`: ボス・クエスト・NPCの日本語/英語名から、既存攻略の説明箇所へ移動する。名前ごとの浅いページは作らない。
- `/search/`: 攻略・ビルド・用語・スキル・装備・名前索引の横断検索。検索状態はURLで共有。カテゴリと日本語/英語別名で絞る。
- `/skills/` と `/equipment/`: 検証した掲載ビルドの参照項目一覧。
- `/skills/{slug}/` と `/equipment/{slug}/`: 各項目の効果・条件・入手方法・採用ビルドを一つのURLで回答。入手保証や固定価格を掲載しない。

## 実装・根拠
`data/core-entities.json` の各段落は `sources` の確認範囲へ番号対応する。個体やジェムレベルで変わる条件は実物表示を優先。ビルドへの逆リンクは現在Lvナビの変更なしで追加する。
名前索引は既存攻略の実在アンカーを生成時・テスト時に検証する。検索結果のJS無効時もリンク本文をHTMLで提供する。OGは既存の共用画像を使い、新しい画像を追加しない。

検索順位・AI回答への採用は保証しない。特殊AI用ファイルやFAQリッチリザルトの約束を加えず、本文・見出し・内部リンク・canonical・構造化データを一致させる。

## 検証
`OG_METADATA_ONLY=1 npm run build`、`npm test`、`npm run test:discovery`。
ローカルChromiumはsocket権限制限が既知。DOM検証と実画面の375/390/430px検証を区別する。`/tests/mobile.html` の `siteSearch`、`nameIndex`、`skillReference`、`equipmentReference` は公開許可後の実描画確認用で、noindexを維持する。

## 初回掲載の範囲
- 名前索引62件、検索125項目（攻略32・ビルド12・用語13・スキル4・装備2・名前62）。既存攻略ハブの30記事カウントは変更しない。検索は別途公開されている攻略ページも含む。
- スキル：ワーリングアサルト、シールドウォール、ツイスター、スパーク。
- 装備：テイミング、スリルスティール。通常品とRuneforging版の条件が混在する資料は確定数値として転載しない。素材投入が必要な非公式レシピは確認範囲と消費前確認を明示する。
- 個別ページから5種の掲載ビルドへ、ビルドから個別ページへ相互リンク。スキルジェム/装備の基本記事から各一覧にも接続する。
- 全体検索の導線を共通メニューへ一つ追加するため、既存生成HTMLにも変更が出る。既存現在Lvナビ、攻略検索のカテゴリ・状態管理を置き換えない。
