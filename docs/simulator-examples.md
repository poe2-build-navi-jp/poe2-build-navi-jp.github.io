# サンプルと撃破装備の確認範囲

操作サンプルはツイスター・ジェムリング、アイスショット・デッドアイ、スパーク・ストームウィーバーの3種。Lv80、主力ジェムLv10、数値比較用の仮装備6点、接続を検証した通常パッシブ3点で構成する。`tools/generate-simulator-examples.mjs`が公開版と同じWASMで、装備エラーなし・正のDPS・ライフの計算結果を検査する。ゲーム内の最適性・入手性を保証する構成ではない。

撃破装備の入力は`data/simulator-records.json`。転記元は既存記事の装備表・文章で、提供画像の確認範囲と日付を引き継ぐ。神性のアービターはLv87と装備10点、ゼシュトは同じ装備10点（Lv未確認）、灰のアービターはLv82と文章で特定できた装備7点。灰のアービターに新しい記録のアクセサリー・ルーン・品質を流用しない。

スキル・サポート・パッシブ・ジュエル・予約は未確認なので空欄。鎧のソケット数・アイドル・絆など適用条件を特定できない効果は補完しない。武器セットはユーザーが試算用の配置を選ぶ。ゼシュトのLv入力も試算用で、撃破Lvと称さない。計算結果を記事の撮影時ステータスの完全再現として表示しない。

どの見本もプレビューだけでは端末の作業・名前付き構成を変えない。取り込みは明示操作で行い、直前の作業を退避する。共有構成の確認中は既存の自分用保存の保護を維持する。出発点を示すoriginは保存・共有時にも引き継ぐ。

名前付き構成はビルドごとに12件。既存の自動保存とは別の一覧で、更新は明示操作のみ。破損した一覧は上書きせず、他タブとの競合は再読み込みを案内する。削除は確認を経て行い、直前の削除は復元可能。A/B比較は敵条件を共通にし、各構成のLv・報酬ポイント・武器セットと、その他の条件は保存時点であることを表示する。
