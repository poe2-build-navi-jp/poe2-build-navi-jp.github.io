# シミュレーターの導線・編集履歴・予定額・比較画像・内訳

1. 共通メニューからシミュレーターと保存一覧へ進める。運営者情報・編集方針・プライバシー・利用規約・サイトマップを含む全148ページが対象。保存一覧は既知の12ビルドの端末保存だけを読み、名前・Lvを表示する。メモは出さない。名前付き保存のリンクでは構成を選択し、明示的な読み込みで作業を退避する。
2. Undo/Redoはビルドを開いている間の直近20操作、保持上限6MB。装備・ジェム・パッシブ・武器セット・Lv・条件・メモの反映を記録する。共有構成の自動保存保護も履歴に持たせる。入力欄の標準Undoを妨げず、別ビルドへ移ると履歴をリセット。名前付き保存は書き換えない。
3. 予定額と予算は構成データと別の端末キーへ保存する。0と未記録を区別し、同通貨のみ予算判定する。相場取得・換算・購入操作はしない。別タブの更新は上書きせず、壊れた保存は保持する。構成更新時には予定額の見直しを案内する。
4. PNGは比較表と同じ計算済みスナップショットから1200×1280で描画する。構成名は既定で除外し、任意で含める。メモ・装備テキスト・共有URLは入れない。敵条件・Lv・武器セット・予定額・対応データ・限界を記載する。状態変更後の古い画像や非同期完了を無効化する。外部の画像・フォント・画像生成APIを使わない。
5. 内訳は公開版と同じWASMのbreakdownsを必要時に取得する。数値・計算段階・効果の出所・適用状態と未対応効果を表示する。スピリットの派生式に対応し、スキル未設定のDPSを表示しない。内訳表示だけでは保存・構成を変更しない。原文が必要な効果は保持し、返されない式を推定しない。装備の基礎値など部位を返さない出所は部位を推定しない。

`npm run test:simulator`は実エンジンで、履歴・価格・出所・共有保護と状態分離を検証する。画像の実ファイルとレスポンシブ表示は公開前のブラウザQAで確認する。
