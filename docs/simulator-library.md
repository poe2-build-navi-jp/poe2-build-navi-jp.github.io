# 保存構成と端末間同期

## 実装対象と確認項目

- 完成入力の見本：全装備スロット、主力・サポートジェム、接続済みパッシブを保存する。計算確認と実プレイ確認を分け、データ版・出典・未確認項目を表示する。
- 保存構成の更新案内：該当する職業と計算データの変更だけを案内する。既読状態を保存し、OSのプッシュ通知とは区別する。
- 比較記録：計算時点の二つの構成、数値、レベル、敵、設定、報酬、予算、計算エンジンとデータ版を固定して保存する。条件違いを明記する。
- 同期：名前付き構成・比較記録を暗号化して端末間で同期する。一時編集中の構成は切り替えない。接続コードを知る端末だけが復号できる。

## 同期サービス

既存のGitHub Pagesを維持し、AppDeployのデータベースに暗号文だけを保管する。フロントエンドからのリクエストはAppDeploy SDKを使う同一オリジンの中継フレームを通る。中継は親ウィンドウと許可したオリジンを確認する。ネイティブのブリッジは従来どおりメインフレームのサイトに限定する。

実装ファイル：`tools/sync-service/backend/index.ts`、`tools/sync-service/src/main.ts`、`tools/sync-service/src/vault.js`、`tools/sync-service/tests/tests.json`、`assets/simulator-library*.js`、`assets/simulator-sync*.js`、関連CSS・データ・ジェネレーター。

接続コードは256bitの乱数。HKDFで認証用と暗号用を分離し、AES-GCMで暗号化する。サーバーには認証トークンのハッシュと暗号文を保存し、コード・構成名・装備本文はログ・解析・共有URLに含めない。同期容量は復号前のJSONで2MiB。上限超過や障害時にも端末の保存を保持する。

更新はリビジョンの条件付きトランザクションで行う。直近32件のリクエストIDとペイロードハッシュを変更と同じトランザクションで記録する。不確定な応答では同じリクエストを再送する。競合は三方向の比較で別名コピーを残す。削除は墓標を同期し、古い端末が構成を復活させない。保管庫を無効化した後は読み書きを拒否する。

## 公開前チェック

サービスのE2Eは、保管庫の作成・再読込、別端末の接続と変更、誤コードの拒否、保管庫の無効化をそれぞれ独立して確認する。これらがcreate/read/write/revokeの全ルートをカバーする。ローカルテストでは暗号の改ざん拒否、競合時のコピー、削除、保存枠・容量上限、CAS競合、同じリクエストの再送、進行中の編集保持を確認する。英語版と狭いスマートフォン幅でも操作できることを公開前に確認する。

## 運用

本番中継は https://poe2-olc5ko.v2.appdeploy.ai/ （アプリID: `poe2-olc5ko`）。同じアプリIDで更新し、公開前にはホスト側の最新ソースを取得する。環境変数やサーバーの秘密鍵は不要。クライアントの接続コードはシミュレーターの構成バックアップと別の名前空間に置き、ネイティブの一括バックアップにも含めない。データベースは固定テーブル `poe2_vaults` と `poe2_vault_chunks`。保管庫の無効化時には両方のチャンクバンクを消し、コードの再利用を拒否する。

保存後の育成ガイド変更は、パッシブ・装備・スキル等の案内を含むプリセットの内容ハッシュで検知する。現行版を保存データに記録し、次の公開時に対応する構成だけに案内する。計算データの変更も版で検知する。関連リンクは記事側の共通バーにも表示するが、構成内容を解析へ送信しない。

参考完成構成はツイスター・ジェムリングとアイスショット・デッドアイの2件。装備条件・接続・ポイント上限・装備読込・正の主力DPSを確認済み。実プレイや1.0互換性は未確認。一部の付与スキル等は計算対象外。Sparkの参照ツリーは特殊取得を含み、同じ条件で接続を検証できなかったため、完成見本には含めない。既存の小さな操作サンプルは残している。
