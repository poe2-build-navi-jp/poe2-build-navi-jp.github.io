# 装備の写真取り込み

シミュレーターの装備部位を開き、「カメラで装備を撮る」または「装備画像を選ぶ」から使います。スマホでは背面カメラ用の撮影入力、PCでは画像ファイルの選択を利用できます。写真はアップロードせず、同じサイトから読み込んだTesseract.js 7.0.0で端末内処理します。日本語と英語を選べます。

装備の説明欄を大きく撮影し、範囲を調整して文字を読み取ります。ベースと品質、候補の数値、未認識の行を写真と照合してください。OCRテキストを修正すると候補を再判定します。確認した候補は装備テキストへ入るだけで、「この装備を反映」を押すまで構成・保存・計算結果は変わりません。反映後は既存の戻す・やり直すに対応します。

対応するのは編集カタログにある35種類の定型オプションです。最大ライフ・マナ・ES、耐性、能力値、速度、追加ダメージ等を含みます。固有効果や不確かな文字は未認識として残し、勝手に推測しません。未知のベースは選択が必要です。暗黙・ルーンの効果も撮影対象に含めてください。表示上のアーマー等の合計値は二重に加算せず、ベース・品質・オプションから計算します。品質が未入力なら0として計算します。ゲーム内の全装備・全機構を再現する機能ではありません。

Web版は公開後すぐ利用できます。ネイティブ版はカメラ利用目的を追加したビルド2以降が必要です。iOSはInfo.plistへカメラ・選択画像の利用目的を追加し、Androidは限定した一時ファイルURIで外部カメラを起動します。旧アプリでは撮影を起動せず更新案内を表示します。Webページの更新だけでは旧バイナリへカメラ権限の宣言は追加できません。

確認: `node tools/prepare-equipment-ocr.mjs` の後に `node scripts/test-simulator-photo.mjs` と `node scripts/test-simulator-photo-ui.mjs`。Chromium/WebKitの画像読み取り・レビュー・反映・戻すは `equipment-photo.yml`、iOS/Androidのコンパイルは `mobile-build.yml` で確認します。実機カメラの撮影・権限ダイアログは端末での確認が必要です。
