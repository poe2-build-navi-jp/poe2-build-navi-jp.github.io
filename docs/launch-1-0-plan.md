# PoE2 1.0公開に向けた計画書

作成：2026-11-03。公開サイトには出ない社内メモ（`docs/` は公開対象外）。
担当：運営者（オカピ研究所）、Claude（照合・生成・テスト・マージ）、Codex（指示書に沿った記事追加）。

## 前提（サイトで確認済みの情報）
- 正式版1.0：**2026年12月11日（PST）**、基本プレイ無料。PC（Steam・Epic）、PS5、Xbox Series。開始時刻は未発表。
- 新職業 **Duelist** が1.0で追加。
- **ExileCon 2026：11月7〜8日（ニュージーランド時間）**、オークランド。1.0の詳しい発表が予想される（内容は未確認）。
- 掲載ビルド12本はすべて0.5.5向け。1.0で確認済みは0本。

## 方針
1. **速さと正確さの両立**：公式発表が出たら24時間以内に日本語要約を出す。ただし未確認の内容は「未確認」と書き、予想を確定情報として扱わない（編集方針どおり）。
2. **型を先に作る**：発表当日に書く時間を減らすため、ページの型（データの項目と見出し）を事前に用意する。
3. **既存ページを1.0に更新する**：新しいページを増やすより先に、検索で見られている既存ページ（1.0ハブ、公開日、始め方、職業、初心者向けビルド）を最新にする。
4. **一次情報**：公開週は運営者のプレイ記録とスクリーンショットを最優先で記事にする。

## リスクと対策

| リスク | 対策 |
|---|---|
| 発表・パッチノートの量が多く、要約が遅れる | 型を先に作る。全部を一度に書かず、「確定事項」「ビルドへの影響」を先に出し、詳細は追記する |
| 未確認の情報を急いで載せてしまう | 編集方針どおり「未確認」と明記する。予想・リーク情報は載せない |
| 公開日・内容の変更 | 公式発表で毎日確認し、公開日ページの確認日を更新する |
| ゲームデータの扱い | 一括抽出・大量転載はしない（`docs/database-plan.md`） |
| 複数のAIが同じファイルを同時に直して衝突する | 作業前にmainを取り込み、1つのPRの範囲を小さくする |
