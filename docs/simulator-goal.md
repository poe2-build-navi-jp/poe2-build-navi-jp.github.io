# 目標ビルドまでの不足一覧

シミュレーターの各ビルドで、入力確認済みの参考完成構成または同じビルドの名前付き保存を目標に選べる。目標の入力を独立したスナップショットとして端末に保存する。元の保存を更新・削除しても目標は選び直すまで変わらない。現在の構成、未反映の装備入力、名前付き保存、自動保存、比較記録は目標設定では変更しない。

## 照合内容

- ジェム：有効な同一スキルグループ内で、同じスキルIDを一対一に照合する。別グループのサポートは充足と見なさない。未設定・無効、Lv/品質不足、主力指定の違いを分ける。Lv/品質が目標以上なら充足。未認識IDは未確認と表示する。
- パッシブ：開始点・装飾マスタリーを除き、共有と武器セット別の割当を照合する。能力値の選択違いも分ける。異なるツリー版は未取得数を判定しない。場所を見る操作は選択・取得を適用しない。
- 装備：目標に明示された装備欄の部位・フラスコ/チャーム・両武器セットを照合する。レア/マジックの任意の名前、オプション行の並び、同じ指輪の左右入替を許容し、未設定と入力内容の違いを表示する。性能や取得性を判定する機能ではない。ジュエル・計算条件・実戦操作の完全照合は含めない。

現在Lvと目標Lv、アセンダンシーの違い、計算データ版の違い、未確認項目を表示する。目標の空欄を達成済みと扱わず、未入力と明示する。一致項目は初期状態で隠し、チェックボックスで表示できる。編集の反映・計算・構成の切替時に照合し直す。

## 保存と公開範囲

目標は `poe2-simulator-goal:v1:<preset>` に保存する端末設定。名前付き保存・比較記録の同期とは別で、目標設定そのものは端末間同期・既存バックアップには含めない。UIにも「この端末」と明記する。接続コードやサーバー変更は不要。目標のメモと装備入力用下書きは保管せず、目標名や内容を解析へ送らない。壊れた目標は自動削除・上書きせず、選び直し・設定解除を案内する。

日本語/英語の共通モデルと表示モジュールを使い、従来のページ生成・アセットの内容ハッシュ・スキル/パッシブ画像を維持する。

## 検証

`test-simulator-goal.mjs` は判定モデル、`test-simulator-goal-ui.mjs` は実WASMを使う選択・編集・保存保持・安全な名前表示を検証する。`test-simulator-goal-browser.mjs` はCI上のChromium/WebKitで、日本語/英語、320px/1366px、再読み込み、ビルド間の独立、入力保持、画像、横あふれを確認する。既存シミュレーター・同期の回帰テストも実行する。
