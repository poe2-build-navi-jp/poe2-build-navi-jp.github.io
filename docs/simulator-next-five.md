# シミュレーター：次の5改善（2026-11-12）

1. 選択画面ではプリセット・操作見本の2ファイルのみ取得。翻訳・装備・参考ルートは選択後、WASM起動と並行して取得する（元JSON合計1,285,767→166,542バイト）。計算データは各分割ファイルのサイズとSHA-256を検証してCache Storageへ保存。利用不可・破損時は通常取得へ戻る。バイト進捗と起動段階を表示し、一覧取得失敗・Worker起動失敗・計算中のWorker障害から再試行できる。編集中の構成は保持する。計算用の初回約9.3MBそのものは削減していない。
2. 選択画面で全12ビルドの自動保存・名前付き構成・価格・予算を一括JSONへ書き出し。メモ・構成名も含む旨を表示。復元はビルドとキーを検証し、置き換える保存欄と件数を事前表示。ファイルにない保存欄は保持。事前表示後の更新を検知し、途中失敗した書き込みを巻き戻す。個別保存JSONとは別形式。操作履歴・削除退避・未保存入力は対象外。
3. 現在の構成と選択ビルドの名前付き構成（最大12件）を同じ敵条件で一覧比較。DPS・ライフ・最小元素耐性・予算と同じ通貨の価格で並べ替える。予算内フィルターは価格と予算が設定済みで同じ通貨の候補のみ。自動換算なし、保存内容の変更なし。計算エラー・未対応効果は行ごとに表示。
4. A/B比較から、AにBの変更を単独で適用して再計算。装備は部位単位、ジェムと主力指定・パッシブ・ジュエル・その他条件は各まとまり。相互作用があるため差分を加算できない旨を明記。計算要求だけを作り、構成・履歴・保存は変更しない。編集時は古い結果を無効化。
5. 選択画面に3ステップと入力見本リンク。作業画面から指輪編集・ジェム編集・保存候補比較へ直接移動。実際の選択ビルド・装備件数・保存候補件数を表示。
