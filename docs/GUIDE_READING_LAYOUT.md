# 攻略記事の共通表示

攻略トップは `/guides/`。サイト全体のホーム `/` とは別です。

新規の実践攻略は `data/strategy-guides.json` に追加し、通常どおり `npm run build` を実行します。`generate-strategy-articles.mjs` は出力時に `applyGuideReadingLayout` を適用するため、検索意図データに未登録の新記事でも共通の本文幅・文字サイズ・見出し・目次・表・装備カードの表示を継承します。SEO登録の省略を推奨するものではありません。

従来の初心者向け攻略は検索意図エンハンサーから同じ処理を適用します。共通CSSは `assets/guide-reading.css`。独自ページを手書きする場合もこのヘルパーを出力時に通し、記事内の既存クラスを再利用してください。辞典・ビルド詳細・一覧には無条件で適用しません。

`npm test` に共通レイアウトの継承・冪等性・本文とメタデータ維持の回帰確認を含めています。新記事の事実、出典、実プレイ確認範囲は別途確認が必要です。
